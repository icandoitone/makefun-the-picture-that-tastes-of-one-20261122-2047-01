One perfect ripe strawberry, and nothing else. Drawn procedurally with PIL, the berry fills the frame — glossy scarlet skin catching the light, pale gold seeds, dew drops beading on its surface, and a fresh green calyx on top — against a dark background that makes the red glow. One look and you can taste it.

## Run it

```sh
python3 main.py
```

This writes `/output/entry.png` (1024x1024 PNG, under 1 MiB). The program is fully deterministic: run it twice and the output is byte-identical. It uses only the Python standard library and Pillow, with no network access.
